# Concordia International Weightlifting Club

Website for the Concordia International Weightlifting Club (CIWC), a community Olympic weightlifting
club in Montréal founded in 2002. Live at **[ciweightlifting.ca](https://ciweightlifting.ca)**.

The site shows the club's training schedule and location, its sponsors, the latest videos from the
club's YouTube channel, and a contact form for anyone interested in joining.

Built with plain HTML, CSS and JavaScript and hosted on GitHub Pages. Club details (schedule, sponsors,
links) are kept in one `CONFIG` block at the top of `main.js`.

Photos, the CIWC logo and sponsor logos belong to the club and the respective sponsors and are not
licensed for reuse.
